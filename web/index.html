Bar, notifications, lock screen, menus, wallpaper — declared in one .wisp file, compiled to C, linked against libc and libm alone.

What one binary replaces

whole shell
Bar, hover panels, notifications, app menu, session lock, night-mode gamma, wallpaper. No mako, no waybar, no swaylock.
declared, compiled
A .wisp file lowers to C. What you declare exists; what you don't declare isn't in the binary.
raw wire
Wayland and D-Bus are spoken directly. No libwayland, no libdbus, no cairo, no glib.
zero idle cpu
No timer, poll, or repaint fires when nothing animates. Idle means zero ticks per second — same law this page obeys: no trackers, no CDNs, no animation loops.
two link deps
libc and libm. The default font backend bakes a TTF into const tables, so the daemon has no font dependency at all.
live reload
wispctl reload re-execs the daemon in place; rebuild crossfades to another config without a flash.
curl -fsSL https://raw.githubusercontent.com/darealhoks/wisp/main/install.sh | sh

Needs a compositor with wlr-layer-shell-unstable-v1; workspace tags come from ext-workspace-v1 (sway, niri, hyprland, labwc, cosmic, kwin) or mango's IPC. Not versioned, not released; it runs one desktop so far: mine.
